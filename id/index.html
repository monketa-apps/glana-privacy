Glana · Kebijakan privasi

Terakhir diperbarui: 14 November 2026.

Singkatnya: Glana hanya bekerja di ponsel Anda. Aplikasi ini tidak memiliki akses internet, tidak mengumpulkan data pribadi, dan tidak membagikan apa pun.

Apa yang dibaca Glana. Untuk menemukan file besar dan duplikat, Glana membaca daftar foto, video, dan file audio Anda, serta daftar file di folder yang Anda pilih. Untuk membandingkan kemungkinan duplikat, aplikasi ini juga membaca isinya. Semua ini hanya terjadi di ponsel Anda.

Apa yang disimpan Glana di ponsel Anda. Hasil pemindaian terakhir, sidik jari file yang digunakan untuk mengenali duplikat, total ruang yang dikosongkan, setelan Anda, dan sampah. Selama berada di sampah, file dari folder yang Anda pilih disalin ke penyimpanan pribadi aplikasi; foto, video, dan file audio tetap berada di sampah Android sendiri. Mencopot pemasangan Glana menghapus semua ini, termasuk salinan tersebut.

Apa yang dikirim Glana. Tidak ada. Glana tidak memiliki izin internet, sehingga tidak dapat mengirim data ke mana pun. Aplikasi ini tidak menggunakan layanan analitik, iklan, atau pelaporan error. Sebuah file hanya sampai ke aplikasi lain saat Anda sendiri membukanya dengan “Buka dengan”.

Izin. Glana meminta akses ke foto, video, dan file audio Anda, serta ke folder yang Anda pilih sendiri. Jika Anda mengizinkan, Glana juga menggunakan pengelolaan media, sehingga Android tidak meminta konfirmasi kedua saat Anda menghapus foto dan video. Anda dapat mencabut setiap izin di setelan Android.

Perubahan. Jika kebijakan ini berubah, versi barunya hadir bersama pembaruan aplikasi dan tanggal baru di bagian atas.
