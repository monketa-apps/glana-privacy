Glana · Kebijakan privasi

Glana membantu Anda mengosongkan ruang di ponsel. Untuk itu, aplikasi ini membaca daftar foto, video, dan file audio Anda, serta daftar folder yang Anda pilih. Untuk menemukan duplikat, aplikasi ini juga membaca isi file yang dibandingkannya. Semua ini terjadi di ponsel Anda.

Glana tidak memiliki akses internet, jadi tidak dapat mengirim apa pun. Aplikasi ini tidak mengumpulkan data pribadi, tidak menggunakan layanan analitik, iklan, atau laporan error, dan tidak membagikan apa pun. File hanya diteruskan ke aplikasi lain jika Anda sendiri membukanya dengan “Buka dengan”.

Di ponsel Anda, Glana menyimpan hasil pemindaian terakhir, sidik jari yang dipakai untuk mengenali duplikat, total ruang yang telah dikosongkan, dan setelan Anda. Aplikasi ini juga menyimpan sampah selama durasi yang Anda pilih: salinan file dari folder pilihan, sedangkan foto, video, dan file audio tetap di sampah Android. Meng-uninstal aplikasi menghapus semua ini, termasuk salinan tersebut.

Aplikasi ini meminta akses ke foto, video, dan file audio Anda, serta ke folder yang Anda pilih sendiri. Jika Anda izinkan, aplikasi ini juga menggunakan pengelolaan media, yang menghindarkan konfirmasi kedua dari Android. Anda dapat mencabut masing-masing izin ini di setelan Android.
